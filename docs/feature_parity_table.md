# 云匣(CloudBox) ↔ 蓝云 功能对照表（只读分析，未改任何代码）

> 方法：完整通读 CloudBox 全部相关 Kotlin（105 文件），逐个功能对照「蓝云」已解密还原的 Lua 逻辑（`apk_analysis/src_readable/`）。
> 状态口径：**可用** / **半成品**（有骨架但功能不成立或体验残缺）/ **缺失**（蓝云有、CloudBox 无）/ **存疑**（证据不足）。

---

## 0. 结论速览

- CloudBox 的**骨架很完整**（数据/网络/DI/Room/WorkManager/CI），**塌的是上层业务流程**——因为它是在没有蓝云源码的情况下、照公开 API 资料"猜"出来的。
- 分三类问题：
  1. **真 Bug（会毁数据/直接不可用）**：下载下到 HTML、重命名文件夹清空描述、搜索点不动、Cookie 导入假登录。
  2. **半成品（形同虚设）**：i18n（切英文没用）、应用自更新（只比版本号）、二维码不含提取码、个人分享链只能设不能看。
  3. **缺失（蓝云有、CloudBox 没有）**：全盘加载、图标包、公告系统、关于页 FAQ/许可/反馈、通知细项开关、账号面板。
- CloudBox **反超**的点（应保留）：Cookie 临期静默重登、动态取色、全局崩溃处理、上传稳定性、域名三层配置、备份默认不含凭据。

## 1. 最痛清单（P0，建议先修）

| # | 问题 | 影响 | 根因（已定位） |
|---|---|---|---|
| 1 | **直接下载得到几 KB 的 HTML 网页** | 核心功能不可用 | 解析层(OkHttp)已正确拿到直链，但真正下载用系统 **DownloadManager**，只带了 UA+Referer、**拿不到解析时得到的 cookie（acw_sc__v2）** → 服务端风控返回挑战 HTML、被当文件保存。蓝云是把全量 cookie 写进 `android.webkit.CookieManager` 再下载。 |
| 2 | **重命名文件夹会清空"简介/描述"** | 静默丢数据 | `FileRepositoryImpl.rename()` 走 task=4（**整体覆盖**）却只传了新名字、未回填原描述。 |
| 3 | **搜索"能搜出来但用不了"** | 模块残缺 | 搜索结果列表**没有 onClick**；进搜索页**不自动同步索引**；文件夹结果 `parentId=-2` 无法定位。 |
| 4 | **Cookie 导入不校验（假登录）** | 用户被误导 | `AuthRepositoryImpl.importCookie()` 直接落盘即算成功，不做 task=47 探测；非法/过期 Cookie 也显示"登录成功"。 |
| 5 | **i18n 是假功能** | 设置形同虚设 | 有 `system/zh/en` 选择、`wrap()` 也接线了，但 `strings.xml` **只有 app_name**，界面全是硬编码中文 → 切英文没用。 |

## 3. 缺失清单（蓝云有、CloudBox 完全没有）

**功能类**：全盘加载 · 图标包(zip)导入 · 公告/消息系统 · 内置文件选择器 · 应用内自更新(下载+安装+强制) · 账号面板(昵称/会员/空间/分享链查看) · 换绑手机 · 会员购买入口 · 关于页 FAQ/许可/反馈/捐赠 · 星标文件夹 · 完整历史更新日志
**设置类**：消息/通知(推送/铃声/流量/删除二次确认/剪贴板开关) · 行为/权限(无障碍/返回缓存) · 文件选择器(双行/唤醒锁/下载改名/搜索模式) · 下载设置(第三方下载器/应用直链/自定义下载位置/链接替换) · 统计与更新服务开关 · 日志/调试 · 字体与主题色 · 签名篡改检测
**备份类**：账号信息备份 · 密码保护 · 备份码形式 · 增量恢复

## 4. 反向清单（CloudBox 比蓝云更好，务必保留）

Cookie 临期静默重登 · 动态取色(Android12+) · 全局崩溃 handler+独立错误页 · 上传稳定性(假成功链/会话恢复/防竞态/失败明细) · 域名三层配置+远程校验+连通性测试 · 备份默认不含凭据 · 数字 uid 注入拦截器(修了旧 bug)

## 5. 待核实（本轮未证，不定论）

1. 下载端是否有「`.zip` → 原名还原」逻辑（决定后缀伪装是否闭环）。
2. `MainActivity` 的 `ShareIntentHandler.parse` 结果是否完整接线到上传/解析。
3. 回收站文件名正则与蓝云不一致 → 需实测条目名是否正确。
4. `LoginScreen` 冷启动是否免二次登录（`startDestination` 恒 LOGIN）。

## 6. 建议修复优先级

- **P0（先修，直接影响能不能用）**：① 下载 cookie 贯通（下 HTML）② 重命名文件夹丢描述 ③ 搜索可点击+自动同步 ④ Cookie 导入校验 ⑤ i18n（或先去掉英文选项）
- **P1（补齐核心体验）**：账号面板(getUserInfo) · 应用自更新闭环 · 公告系统 · 全盘加载 · 二维码含提取码 · 回收站正则+二次确认 · 新建文件夹用服务端 id
- **P2（锦上添花）**：图标包 · 备份增强(账号/密码/增量) · 设置项补全 · 抽屉/加号菜单 · 关于页信息 · 字体/主题色
