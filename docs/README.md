## 原版源码（55 个明文 Lua）在哪

**不在本仓库。** 位置与复现方式见 `original_apk_reverse_report.md`：
样本 APK 经 `deobf.py`（容器解密 + 字符串解密）→ unluac 反编译 → UTF-8 转义还原，
得到 55 个可读 Lua 源码（90,066 行），目录名 `src_readable/`。

需要重新复现时的依赖：`lua-5.3.6.tar.gz`、`unluac.jar`、`luabc.py`、`verify.py`
（均在上表报告所述的沙箱分析目录 `apk_analysis/` 内）。

## 生成方式

以上审计文件由 AI 在 2026-09-20 ~ 09-23 期间生成，
方法为**完整通读全仓 Kotlin 源码 + 与原版明文 Lua 逐项对照**，
每一条结论都标注了被验证对象与出处；证据不足者明确标为"未能核对"，未冒充实测。
